# Repository overview — short summaries

- pnperl/Equity — Stock market analysis notebooks for research and prototyping focused on Indian equities.
- pnperl/Hosted — Leader-sentiment analysis tools and notebooks for extracting, processing, and visualizing sentiment from leader communications.
- pnperl/TaxTrack — Track tax liabilities and payments by pay period with simple apps and notebooks for summarizing and exporting tax data (see taxtrack_pro/README.md for details).
- pnperl/nfp-dashboard — Dashboard and scripts to analyze the U.S. Non-Farm Payroll (NFP) report and its market impact; includes trade signal generation around monthly releases.
- pnperl/StockEarn — Scripts and notebooks for earnings-driven stock analysis, including data ingestion and HTML report generation.
- pnperl/Heiken-Ashi-Screener-HA-reversal — Notebooks and code implementing Heiken-Ashi-based screeners and reversal detection for exploratory analysis and backtesting.
- pnperl/Public_trading_bot — Prototype trading bot and research code for data collection, signal generation, and execution simulations.
- pnperl/Equity-Intelligence — Notebooks and Python modules for equity research; converts notebook research into reusable tools for analysis and visualization.
- pnperl/affiliate-link-bot — Notebooks and utilities for managing and generating affiliate links; includes scraping prototypes and alerting examples.
- pnperl/RRG-Sector-Rotation-India-pp — Python tools for Relative Rotation Graph (RRG) based sector rotation analysis tailored to Indian markets.
